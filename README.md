FMM_ETL è una pipeline ETL in Python per il progetto [FantaManageriale](https://github.com/albertomelegatti/webAPP_FantaManageriale). Automatizza il download del listone Fantacalcio, l’elaborazione e normalizzazione dei dati tramite Pandas, e la sincronizzazione con Google Sheets e Supabase/PostgreSQL. Include inoltre strumenti per il backup del database e la copia dei dati tra ambienti di produzione e sviluppo, utilizzando credenziali e configurazioni tramite variabili d’ambiente.
